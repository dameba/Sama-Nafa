Connect Sama Nafa to its private database

This version needs a Supabase project before anyone can sign in. The public connection values belong in app-config.js; never put a service-role key in this file.

  1. Create a Supabase project.
  2. Run supabase/schema.sql in its SQL Editor.
  3. Copy the Project URL and publishable key into app-config.js.
  4. Deploy the invite-member Edge Function with its server-side secrets.

After setup, refresh this page. No financial records are stored in this browser.
